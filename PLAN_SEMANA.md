## 🔑 REGLAS CLAVE ESTA SEMANA

### ✅ En Pesado (Lunes)
1. **Peso = igual** (50kg Press)
2. **Reps = +1 a +2 vs última semana**
   - Si antes hiciste 23 reps total Press → hoy 24-25
   - Pequeño ✔️, pero suma
3. **No hagas fallo muscular** = mantén 2-3 reps en reserva
4. **Nota los números** → impórtalo después para ver progresión

### ✅ En Hipertrofia (Viernes)
1. **Peso = 10-15% menos que Pesado** ✓ (ya lo haces)
2. **Reps = 8-12 en principales** → recuperar si bajaste
3. **Accesorios = más reps** (Elevaciones 15, Bíceps 10+)
4. **Objetivo:** 150-180 reps totales la sesión

### ✅ Timing Running
```
Lunes:  GYM PESADO (intenso)
Martes: Running suave (activo recovery)
Miércoles: GYM PIERNA (intenso)
Jueves: Running fuerte (ya recuperado)
Viernes: GYM HIPERTROFIA (moderado)
Sábado: Running moderado
Domingo: Descanso
```

**Lógica:** Los días de running fuerte (jueves, sábado) vienen después de días de descanso relativo en gym → mejor recuperación
